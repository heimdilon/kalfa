One-line: tinted square glyph tile — Kalfa's stand-in for an avatar.

```jsx
<IconTile icon="user" />
<IconTile icon="message-square" tone="accent" />
<IconTile icon="shield-check" tone="warn" size={40} />
```

Kalfa has no photographic avatars anywhere. Author identity is a glyph tile: user = `user`, agent = the copper mark tile, tool = the tool's own glyph.
