One-line: small state label — run status, terms version, isolation state, plugin trust level.

```jsx
<Badge tone="ok" dot>Tamamlandı</Badge>
<Badge tone="accent">Sürüm 3 · Önemli değişiklik</Badge>
<Badge tone="warn" icon="shield-alert">Yalıtımsız</Badge>
```

Tinted fill + hairline border at the same hue — never a solid saturated block. Badges state facts; they are never clickable (use `Button size="sm"` for that).
