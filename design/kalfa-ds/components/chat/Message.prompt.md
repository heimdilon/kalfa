One-line: one turn in the conversation — the user's is a bordered raised card, Kalfa's sits directly on the app background.

```jsx
<Message author="user" time="14:28">Kimlik doğrulama akışını gözden geçirir misin?</Message>
<Message time="14:29" streaming>Elbette. Kimlik doğrulama akışını inceledim.</Message>
```

Only the user's message gets a container; Kalfa's output is unboxed so tool cards and summaries below it read as part of the same voice.
